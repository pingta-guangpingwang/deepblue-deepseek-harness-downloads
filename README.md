# 深蓝角色扩展

面向深蓝DSH启动器角色空间的可选原生插件。用户从角色能力页主动安装；安装不会自动开启角色或发送 QQ 消息。记忆与知识可离线使用，QQ 渠道复用用户已配置的小号并隔离会话。

本分支为 `character-plugins-0124`，对应启动器源提交 `31a237006f5ef1fddefc933a5fa4a5bb4241b33c`，用于 0.12.5 的安装镜像（分支名称延续未正式发布的 0.12.4 候选目录）。当前知识引擎 1.0.1、QQ 渠道 1.0.2；知识 1.0.0、QQ 1.0.1 / 1.0.0 保留原发布字节及原镜像地址，供已有安装识别和回滚。

`packages/` 为受版本、大小及 SHA-256 约束的产物，`catalog.json` 包含 GitHub / Gitee 双镜像。`sources/` 包含当前两个插件的实际打包依赖；`npm install && npm run build` 使用 esbuild 0.25.12 重建当前插件并逐个校验大小和哈希。旧版本仅复制已核验的原始资产，旧源码保留于原 0121 / 0110 分支。本包不是独立 QQ 客户端，也不是 AstrBot Python 插件安装器；宿主接口由启动器提供。

宠物 MCP 使用独立按需运行包，见 `character-pet-runtime.json` 与 `vendor/character-pet/README.md`。0.2.3 的自主活动计时修复已通过行为回归和本机原生开启/关闭观察。所有用户账号、密钥、资料和对话均不包含在仓库中。
