# 深蓝角色扩展

面向深蓝DSH启动器 0.12.1 角色空间的可选原生插件。用户从角色能力页主动安装；下载安装不会自动开启角色或发送 QQ 消息。记忆与知识可离线使用，QQ 渠道复用用户已配置的小号并隔离会话。

本分支为 `character-plugins-0121`：QQ 渠道 1.0.1 增加 DSH rc.5 兼容。知识引擎仍为 1.0.0；QQ 1.0.0 保留已发布字节供已有安装识别和回滚。两个旧版本的下载地址仍指向原 `character-plugins-0110`，不得覆盖该分支的资产。

`packages/` 为受版本和 SHA-256 约束的构建产物，`catalog.json` 包含双镜像信息。`sources/` 为当前版本源文件；`npm install && npm run build` 重建当前两个插件并逐个校验大小和哈希，历史 QQ 1.0.0 仅复制已校验的原始资产（原源码在 0110 分支）。宿主接口由启动器提供，本包不是独立 QQ 客户端。原版 AstrBot Python 插件不属于此运行格式。

宠物 MCP 使用单独的按需运行包，不混入这两个小插件。所有用户账号、密钥、资料和对话均不包含在仓库中。
